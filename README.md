### 1) 개요

> 전통적인 대형마트 성장세의 둔화
<img width="986" height="412" alt="이미지1" src="https://github.com/user-attachments/assets/34f56dc0-337e-46b8-a1bf-94b0170b9eb6" />

편리한 모바일 쇼핑, 빠른 배송, 비교적 저렴한 가격 등으로 인해 소비자들은 점점 온라인 플랫 폼으로 이동하고 있으며 이로 인해 오프라인 매장의 고객 유입은 지속적으로 감소하고 있습니다. 실제로 대형마트, 백화점, 쇼핑몰 등 오프라인 유통채널은 객수와 매출 모두 정체 또는 감소세를 보이고 있으며, 특히 코로나19 이후에는 이러한 흐름이 구조적 변화로 자리잡았습니다.

<br>

> 생존을 위한 디지털 전환의 필요성

단순히 제품을 진열하고 판매하는 공간을 넘어, 고객을 이해하고, 분석하고, 맞춤형 경험을 제공 하는 공간으로 전환해야 합니다. 하지만 대부분의 오프라인 매장은 실제 방문 고객의 성별, 연령대, 체류 시간, 재방문률과 같은핵심 정보를 파악하기 힘들며 이는 오프라인 매장 특성상 뚜렷한 단점으로 작용하여 온라인 플랫폼과의 정보 비대칭을 심화시킬수 있습니다. 본 프로젝트는 기존 CCTV를 단순 보안 목적이 아닌, A를 통해 고객의 출입, 성별, 연령대, 차량 정보 등을 통합적으로 자동 분석하고, 이를 기반으로 고객 흐름 및 특성, 체류 시간, 시간대별 방문 추이 등을 데이터 기반으로 시각화하고 전략화할 수 있는 플랫폼을 개발하여 오프라인 매장의 생존 및 발전에 기여하고 더 나아가 지역사회 발전에 도움을 주고자 합니다.

### 3) 시스템 아키텍처 및 흐름

## 1. CCTV 영상 수집 및 스트리밍
* FFmpeg 서버에서 각 CCTV 영상을 수신
* 구역별(주차장, 1층, 2층) 영상 프레임을 생성
* 생성된 프레임을 AI 서버와 Spring Boot Backend로 전달

```
+-----------------------+
|         CCTV          |
+-----------------------+
            |
            v
+-----------------------+
|     FFmpeg Server     |
+-----------------------+
            |
    +-------+-------+
    |               |
    v               v
+-------+       +-------+
|  AI   |       |Spring |
|Server |       | Boot  |
+-------+       +-------+
```

> FFmpeg는 실시간 CCTV 영상을 받아 프레임 단위로 처리하고 스트리밍하기 위해 사용했습니다.

## 2. AI 영상 분석
각 구역마다 AI 모델이 영상을 분석합니다.

2-1. 주차장

```
+-------------------+
|    영상 프레임     |
+-------------------+
          |
          v
+-------------------+
| YOLO (차량 탐지)  |
+-------------------+
          |
          v
+-------------------+
|YOLO (번호판 탐지) |
+-------------------+
          |
          v
+-------------------+
|     PaddleOCR     |
+-------------------+
          |
          v
+-------------------+
|   차량 번호 추출  |
+-------------------+
```

추출한 번호판 정보는
```
+-------------------+
|     AI Server     |
+-------------------+
          |
          | HTTP
          v
+-------------------+
|    Spring Boot    |
+-------------------+
```
로 전달됩니다.

2-2. 1층 매장 입구
```
+---------------------+
|     영상 프레임     |
+---------------------+
           |
           v
+---------------------+
|  YOLO (사람 탐지)   |
+---------------------+
           |
           v
+---------------------+
|    EfficientNet     |
+---------------------+
           |
           v
+---------------------+
|  성별 / 연령대 분류 |
+---------------------+
```
분석 결과는
```
+-----------+
| AI Server |
+-----------+
      |
      | HTTP
      v
+-----------+
|Spring Boot|
+-----------+
```
로 전달됩니다.

2-3. 2층 매장
동일한 과정으로
* 사람 탐지
* 성별/연령대 분석
후 HTTP로 Backend에 전송합니다.

## 3. Backend(Spring Boot)
Spring Boot에서는 크게 데이터 처리와 영상 스트리밍을 담당합니다.

3-1. AI 분석 결과 저장
AI 서버에서 전달받은
* 차량 번호
* 성별
* 연령대
등을
```
HTTP
        |
        v
+---------------+
|  Spring Boot  |
+---------------+
        |
        | 
        v
+---------------+
|  MySQL (RDS)  |
+---------------+
```
에 저장합니다.

3-2. 영상 저장
필요한 영상은
```
+---------------+
|  Spring Boot  |
+---------------+
        |
        | 
        v
+---------------+
|    Amazon S3  |
+---------------+
```
에 업로드 합니다.

3-3. 실시간 영상 스트리밍
Backend는 FFmpeg로부터 전달받은 프레임을 인코딩한 후
(그림)
로 실시간 전송합니다.

4. Frontend (React)
React는
```
+-------------------+
|    Spring Boot    |
+-------------------+
          |
          | WebSocket
          v
+-------------------+
|       Nginx       |
+-------------------+
          |
          v
+-------------------+
|     Frontend      |
+-------------------+
```
을 수행합니다.
또한
```
+----------------------------+
|         WebSocket          |
+----------------------------+
               |
               v
+----------------------------+
|      실시간 프레임 수신      |
+----------------------------+
               |
               v
+----------------------------+
| Canvas 또는 Video 화면 렌더링 |
+----------------------------+
```
을 통해
* 차량 정보
* 방문자 통계
* 대시보드 데이터
등을 조회합니다.

5. 사용자 (Web Browser)
사용자는 브라우저에서
* 실시간 CCTV 영상 확인
* 차량 정보 조회
* 방문자 통계 확인
* 관리자 기능 수행
등을 이용합니다.

| **조건별 상세 조회** | • 날짜, 시간, CCTV ID를 조건으로 설정한 후 '확인' 버튼을 클릭하여 조회를 진행합니다.<br>• 선택한 기간에 맞춰 **전체 재방문률** 및 **요일별 재방문률**을 재계산하여 차트로 시각화합니다. |
